# Getting Started with DClaw Learn

DClaw Learn is an adaptive learning platform with AI quiz generation, progress tracking, discussion forums, and assignments. This section covers setup, configuration, and first use.

## Prerequisites

| Tool | Minimum Version | Notes |
|------|----------------|-------|
| Docker | 24+ | Required for all-in-one local dev |
| Docker Compose v2 | bundled with Docker Desktop | Used by `docker compose up` |
| Node.js | 20+ | Only needed for frontend-only dev |
| Python | 3.11+ | Only needed for backend-only dev |
| Ollama | any | Optional — enables real AI quiz generation |
