# Roadmap

## v1.2 — Completed (May 2026)

- [x] User authentication (JWT, register/login)
- [x] Lesson progress tracking with completion percentage
- [x] Certificates on course completion
- [x] Real AI quiz generation via Ollama (llama3)
- [x] Video lesson support (YouTube/Vimeo embed)
- [x] Content recommendations (category + difficulty scoring)
- [x] Discussion forums per course
- [x] Assignments & grading

## v1.3 — Short Term (Q3 2026)

- [ ] Role-based access control (student vs instructor distinction in API)
- [ ] Spaced repetition flashcards (SM-2 algorithm, AI-generated from lesson content)
- [ ] Lesson content editor for instructors (rich text / markdown)
- [ ] Email notifications (assignment graded, certificate issued)
- [ ] Paginated course listing and thread listing

## v1.4 — Medium Term (Q3–Q4 2026)

- [ ] Learning analytics dashboard (time spent, quiz score trends, completion rates)
- [ ] CSV export for analytics
- [ ] Video file upload support (direct uploads, not just embed URLs)
- [ ] OpenRouter support in quiz generation (cloud LLM alternative to Ollama)
- [ ] Logto integration (SSO, replace custom JWT with platform auth)

## v2.0 — Long Term (2027+)

- [ ] Real-time collaboration (live quiz sessions, co-editing notes)
- [ ] Mobile-responsive redesign
- [ ] Plugin system for custom content types
- [ ] Multi-tenant / white-label support
- [ ] Advanced analytics with charting library
